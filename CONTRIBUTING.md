# Contributing

Thanks for your interest in GlobiGuard's open distribution layer.

## Maintainer model

- **GuideGDM** is the maintainer of record for this repository.
- Do not add AI tools or assistants as contributors, maintainers, or authors in
  repository metadata or package manifests.

## Contribution rules

1. Keep the browser outside the trust boundary.
2. Keep public contracts aligned with the canonical spec owned by the main
   `globiguard` repository.
3. Prefer shared core changes over package-local duplication.
4. Update docs when behavior or package setup changes.
