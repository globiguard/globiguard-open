# Security policy

If you discover a vulnerability in this repository, do not open a public issue.

Use GitHub private vulnerability reporting for this repository. If that channel
is unavailable, contact the repository owner on GitHub to request a private
disclosure channel before sharing exploit details.

## Scope

This repository contains public SDKs, contracts, examples, and workflow
integrations. Sensitive tenant authority, privileged runtime behavior, and
production control-plane operations remain server-side product concerns.
